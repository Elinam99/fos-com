# Fos.com

Static fashion marketplace site — landing page, store, portfolio, and founder pages.

## View locally

Open `index.html` in your browser (double-click the file).

## GitHub Pages

After pushing to GitHub, enable **Settings → Pages → Deploy from branch `main` / root**.

Your site will be live at `https://<username>.github.io/fos-com/` (or your chosen repo name).

To use a custom domain like `fos.com`, add DNS records at your registrar and set the custom domain under Pages settings.
